# 출시 전 점검

Archive 하기 전에 한 번 훑는다. 항목은 대부분 실제로 한 번씩 겪은 것들이라, 새로
겪은 문제는 여기에 줄을 추가해서 다음 출시 때 다시 밟지 않게 한다.

## 빌드

- [ ] `CURRENT_PROJECT_VERSION`(빌드 번호)을 올렸는가 — 같은 번호는 업로드가 거부된다
- [ ] `MARKETING_VERSION`이 심사에 올릴 버전과 맞는가
- [ ] 목데이터·디버그 화면이 남아 있지 않은가 (`APIEnvironment.current`가 remote인가)
- [ ] 테스트가 통과하는가

## 설정 파일

- [ ] `APIKeys.swift`에 값이 채워져 있는가 (gitignore 대상이라 새 환경에서는 비어 있다)
- [ ] `AppContacts.swift`에 값이 채워져 있는가 (gitignore 대상)
- [ ] `PrivacyInfo.xcprivacy`가 실제 수집 항목과 맞는가

## App Store 가이드라인

한 번 거절당한 항목이다. 기능을 추가했으면 해당 줄을 다시 본다.

- [ ] **외부 앱으로 넘기는 기능은 iOS 기본 앱 선택지를 함께 제공한다**
      — 길찾기는 애플 지도, 메일은 기본 메일 앱. 서드파티만 제공하면
      Guideline 4(Design)로 거절된다. (#100)
- [ ] 로그인 뒤에도 이용약관·개인정보처리방침에 접근할 수 있는가 (Guideline 5.1.1)
- [ ] 쓰지 않는 권한을 요청하지 않는가 — 기능 없이 권한만 물으면 거절된다
- [ ] 사용자 생성 콘텐츠가 있으면 신고·차단이 있는가 (Guideline 1.2)

## 심사 계정

- [ ] 데모 계정으로 로그인이 되는가
- [ ] **계정에 연결된 여행 기간이 심사 기간을 덮는가** — 여행이 끝나 있으면
      심사자가 핵심 화면을 볼 수 없어 거절 사유가 된다
- [ ] 계정에 일정·채팅·주변 스팟 데이터가 채워져 있는가

## 기기

- [ ] **iPad에서 열어 본다** — 심사는 iPad에서 진행되는 경우가 있다.
      iPhone 전용 앱도 iPad 호환 모드로 열리며, 이 화면이 심사 대상이 된다
- [ ] 가장 작은 기기(iPhone SE 계열)에서 잘리는 곳이 없는가
