# [HiTrip 앱] 기획 확정 요청 (2026-09-11)

## 1. 값 확정 (앱에 넣기만 하면 되는 것)

- **약관 전문 URL 5개**: 서비스 이용약관, 개인정보 수집·이용, 위치기반서비스, 건강정보(민감정보), 푸시 알림 수신
  - 지금은 「보기 >」를 누르면 "주소가 아직 등록되지 않았습니다"가 뜹니다.
- **로그인 [문의하기]**: 연결할 채널(카카오톡 채널, 웹 폼, 이메일 등)과 버튼 문구
  - 지금은 눌러도 이동하지 않습니다.
- **App Store 주소**: 강제 업데이트 팝업의 [업데이트] 버튼용
- **비밀번호 규칙**: 최소 길이, 영문·숫자·특수문자 조합 필수 여부
  - 앱은 지금 8자 이상만 검사합니다.
- **긴급 통역 연결 전화번호와 운영시간**: 연결할 전화번호 및 기관 확정 필요

## 2. 디자인 필요

- **최초 비밀번호 변경 화면**
  - 발급받은 임시 비밀번호로 처음 로그인하면 서버가 비밀번호 변경을 요구합니다.
  - Figma에 이 화면이 없어서 지금은 로그인 화면 스타일로 임시로 만들어 두었습니다.
  
## 3. 기획 결정 필요

- **"앱 내 비밀번호 변경 불가"와 충돌**
  - 기획서에는 SaaS에서만 변경한다고 되어 있지만, 서버는 보안상 첫 로그인 때 변경을 요구합니다.
  - 임시로 앱에 변경 화면을 넣는 쪽으로 진행했으니 확인 부탁드립니다.
- **로그인 입력칸 문구**
  - Figma는 「ID (성함)」·「password (생년월일)」인데, 실제 계정은 여행사가 발급한 아이디·임시 비밀번호입니다.
  - 지금은 「발급받은 아이디」·「비밀번호」로 두었는데, 이대로 갈지 확인 부탁드립니다.
- **동시 로그인 정책**
  - 기획은 「동일한 아이디로 접속중인 기기가 있습니다. 차단하고 로그인하시겠습니까?」 확인을 받는 방식입니다.
  - 현재 서버는 확인 없이 기존 기기를 바로 로그아웃시킵니다.
  - 어느 쪽으로 할지 정해 주세요. 확인 팝업으로 가면 서버 수정이 필요합니다.
- **담당 여행이 여러 개인 안내사**
  - 지금은 진행 중 → 가장 가까운 예정 → 가장 최근 여행 순으로 하나를 자동 선택합니다.
  - 여행 전환 화면이 필요한지 정해 주세요.
